# Featureflow

Командный трекер фич на React Native + Expo + TypeScript. В карточке фичи видно общее выполнение чеклиста и прогресс каждой компетенции. DoR и DoD проверяются отдельно.

## Обещания

- Можно создать фичу из шаблона команды и указать применимые платформы.
- Для каждого пункта доступны «Не начато», «В работе», «Выполнено», «N/A» и комментарий/ссылка. Для N/A обязательна причина.
- Процент = выполнено / применимые пункты. При отсутствии применимых пунктов показывается прочерк. Критерии DoR/DoD не увеличивают процент общего чеклиста.
- Участники одной команды получают общие данные сервера. Есть ручное обновление, опрос каждые 15 секунд и обновление при возвращении в приложение. Во время редактирования автоматическое обновление приостанавливается.
- Одновременное изменение одного пункта не затирает правку коллеги: сервер возвращает конфликт версии. После конфликта приложение загружает актуальные данные; нужно повторно открыть пункт и подтвердить изменение.
- История показывает автора, время и изменение статуса. API также сохраняет комментарий изменения.
- Экран «О приложении» показывает первые семь символов EXPO_PUBLIC_COMMIT или dev.
- Демо содержит вымышленные данные, хранится в памяти и явно отделено от рабочего пространства.

## Запуск приложения

Требуются Node.js 24+ и npm. Проект использует Expo SDK 58: на телефоне нужен Expo Go с поддержкой SDK 58. Навигация — кнопками, без сторонней библиотеки.

```powershell
npm ci
npm start
```

Без адреса API можно открыть «Посмотреть демо». Для команды адрес задаётся перед запуском:

```powershell
$env:EXPO_PUBLIC_API_URL='https://YOUR-TEAM-API.example'
$env:EXPO_PUBLIC_COMMIT=(git rev-parse --short HEAD)
npm start
```

На Android открой QR в Expo Go. На физическом iPhone Expo CLI на компьютере и Expo Go на телефоне должны быть авторизованы в одном Expo-аккаунте: сначала `npx expo login`, затем войди в этот аккаунт в Expo Go. После этого сканируй QR камерой или открой адрес из терминала через Enter URL в Expo Go. Компьютер и телефон должны видеть dev-сервер. Не открывай адрес Metro как обычный сайт приложения.

Если npm отсутствует в PATH, но зависимости уже установлены, Windows-обёртка `expo.cmd` запускает установленный Expo CLI напрямую через Node. Она также умеет найти Node из стандартного локального runtime Codex:

```powershell
.\expo.cmd login
.\expo.cmd start --go --port 8083
```

EXPO_PUBLIC_* попадают в приложение: это адрес сервера и версия, не место для секретов. Для релизного приложения API должен использовать HTTPS. Токен хранится в expo-secure-store, рабочие данные — на сервере, офлайн-редактирования пока нет.

## Приватный API

Python 3.12+, стандартная библиотека, SQLite. Участников создаёт оператор; публичной регистрации нет. Пароли хешируются scrypt, сессии случайные, на сервере хранится SHA-256 токена; срок сессии семь дней. Каждый запрос проверяет команду. Авторизация через Bearer, cookies и CORS не используются.

```powershell
python backend/server.py --db C:/private/featureflow/team.sqlite user --login YOUR_LOGIN --team YOUR_TEAM --name YOUR_DISPLAY_NAME
python backend/server.py --db C:/private/featureflow/team.sqlite template --team YOUR_TEAM --file C:/private/featureflow/template.json
python backend/server.py --db C:/private/featureflow/team.sqlite serve --host 127.0.0.1 --port 21003
```

Пароль вводится скрыто через getpass, не через аргументы командной строки. Путь базы должен находиться вне репозитория. Шаблон — JSON-массив с полями id, text, competence, stage, required, необязательными gate (DoR/DoD) и platform (Android/iOS/PWA/SDUI/Middle). В репозитории есть только [синтетический пример](backend/example-template.json). Реальный шаблон импортируется оператором в приватную БД. Импорт не изменяет уже созданные фичи. Таблица-источник не изменяется; двусторонней синхронизации с Google Sheets нет.

Сервер по умолчанию слушает loopback. Для реальной команды нужен отдельный HTTPS reverse proxy с ограничением размера тела 32 КБ, таймаутами и rate limit на вход. Не публикуй Python HTTP server напрямую. Адрес, TLS, операторские учётные записи, резервное копирование БД и установка на устройства ещё требуют настройки. Не используй общие пароли. Все участники команды пока имеют одинаковые права редактирования; разграничение по компетенциям не реализовано.

## Проверки

```powershell
npm run lint
npm run typecheck
npm test
python -m unittest discover -s backend -v
npx expo export --platform android --platform ios
```

Тесты проверяют N/A, отделение DoR/DoD от общего процента, аудит, изоляцию команд, атомарные конфликты, отзыв сессии, лимит входов и HTTP-контракт. Экспорт Metro проверяет JS-бандлы обеих платформ, но не заменяет установку и испытание на телефоне.
