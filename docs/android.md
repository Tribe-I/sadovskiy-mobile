# Android standalone APK

Профиль `preview` выпускает подписанный release APK со встроенным JS-бандлом, без development client. Expo Go, Metro и вход в Expo на телефоне для его запуска не нужны. Для данных требуется интернет и личная учётка Meribel.

- EAS: @mistersds/checklist, projectId 4fd5ab4d-181d-4f98-8146-8a25f6ee39b2.
- Android package: ru.tribei.sadovskiymobile; версия 1.0.0, versionCode 1.
- HTTPS API: https://tribe-i.ru/sadovskiy-mobile.
- Сессия хранится в SecureStore; Android backup отключён. Пароли и командный шаблон не вшиваются в APK.
- Собственная геометрическая иконка; кнопка «Назад» закрывает редактор/возвращает к списку. В корне действует системный выход.
- Экран «О приложении» показывает EXPO_PUBLIC_COMMIT либо короткий EAS_BUILD_GIT_COMMIT_HASH, записанный build hook. В локальной разработке без этих значений — dev.

Сборка: `eas build --platform android --profile preview`. Первый запуск интерактивный; ключ подписи хранится в EAS credentials, не в Git. EXPO_TOKEN для локальной интерактивной сборки не нужен. Не запускать параллельные повторные сборки, пока текущая не завершена.

После получения APK: скачать на Android по ссылке EAS, открыть файл и подтвердить установку. Если Android запросит разрешение устанавливать из этого браузера, владелец включает его сам для установки. Открыть Featureflow с домашнего экрана, войти выданной учёткой, создать первую фичу. Проверить статус, комментарий и N/A; изменения должны появиться у второго участника после обновления. Затем проверить выход и повторный вход, системную кнопку «Назад» и отображение версии. Эти физические проверки нельзя заменить успешной облачной сборкой.
