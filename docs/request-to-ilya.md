Илья, привет! Для нового командного приложения Featureflow нужен отдельный маршрут **https://tribe-i.ru/sadovskiy-mobile/**. Репозиторий и конфигурация: https://github.com/Tribe-I/sadovskiy-mobile/pull/1.

Просьба согласовать и настроить изоляцию до публикации:

- отдельный пользователь ОС `sadovskiy-mobile` без привилегий и доступа к данным соседних приложений;
- свой PM2 daemon/процесс, каталог кода для чтения и приватный каталог `/var/lib/sadovskiy-mobile` для SQLite и журналов; лимиты CPU/RAM подготовлены;
- nginx location `/sadovskiy-mobile/` в существующем HTTPS-vhost домена, с ограничением размера запросов, таймаутами и rate limit;
- backend только на loopback; предлагаем порт 21003, если он свободен и допустим по правилам хоста. Публично открывать этот порт не нужно, вход идёт через уже используемый HTTPS 443;
- согласованный способ доступа/выкладки: сейчас SSH к tribe-i.ru из моей рабочей среды даёт таймаут. Могу передать приватную БД по защищённому каналу, файлы открытых паролей на сервер не нужны.

Старые лендинги и сервисы не меняем. Все конфиги в deploy/ пока черновики: нужно проверить на хосте и применить штатно. После этого подключу адрес API в Android и проверю вход и общие изменения с двух устройств.
