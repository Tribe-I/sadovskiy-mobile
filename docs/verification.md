## Совместимость с Expo Go SDK 58

После подтверждённой на Android ошибки несовпадения SDK проект обновлён с SDK 57 до SDK 58. Совместимые версии установлены через expo install --fix: React 19.3.0, React Native 0.88.1, SecureStore 58.0.2 и StatusBar 58.0.4.

- expo install --check: зависимости совместимы.
- expo-doctor: 20/20 проверок успешно.
- lint, TypeScript, 3 теста модели и 6 тестов API: успешно.
- Экспорт Hermes-бандлов Android/iOS на SDK 58: успешно.
- Запущенный Metro отвечает HTTP 200 и sdkVersion 58.0.0 на запросы манифеста Android и iOS.
- npm audit: 12 moderate, 0 high/critical; без devDependencies — 5 moderate.

Добавлена Windows-обёртка expo.cmd для запуска установленного CLI, когда npm отсутствует в PATH. Для физического iPhone нужен вход в один Expo-аккаунт на компьютере и в Expo Go. iOS отложен владельцем. Запуск интерфейса на Android после обновления подтверждён владельцем; доступно демо, потому что рабочий API ещё не подключён.

## Подготовка изолированного API на основном домене

Целевой путь: https://tribe-i.ru/sadovskiy-mobile/. Подготовлены PM2-конфигурация для отдельного пользователя ОС, nginx location и systemd drop-in; на хосте они не применялись. Nginx в локальной среде отсутствует; целевой nginx -t остаётся задачей администратора.

Python API ограничен восемью обработчиками запросов; неполные заголовки закрываются по таймауту. Проверки перегрузки (503) и таймаута добавлены к API-набору. После изменения: lint, TypeScript, 3 теста модели и 8 тестов API успешно. Синтаксис PM2-конфига проверен node --check; Python smoke-скрипт компилируется. Живой HTTPS smoke до публикации API не запускался.

Локальная приватная БД содержит подготовленные учётные записи и шаблон команды, вне репозитория. Значения паролей, список участников, база и реальный чеклист не включены в PR. Пример EXPO_PUBLIC_API_URL добавлен только в .env.example; рабочий адрес ещё не активирован.
